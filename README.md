# Resume Builder — Project 3

A browser-based resume builder created for the GenAI Internship Week 2, Section A: Web Tools.

## Features
- Form-based personal, education, skills, project and experience details
- Live A4 resume preview
- Three visually different resume templates
- Drag-and-drop section ordering
- Export to PDF using the browser print dialog
- Save resume data as JSON and load it later
- Resume details are processed locally in the browser

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or another modern browser.
3. Enter your information and choose a template.
4. Drag sections to reorder them if needed.
5. Click **Export PDF** and choose **Save as PDF**.
6. Use **Save Data** to download a JSON backup. Use **Load Data** to restore it.

## Offline use
The project uses local HTML, CSS and JavaScript and does not require an internet connection to run after the files are downloaded.

## Notes
- Replace the sample name with your preferred full name if needed.
- This project uses browser printing for PDF export; page breaks depend on the amount of resume content and should be checked before submission.
